## Термодинамика вырожденных праймеров

Каждая вырожденная позиция в праймере раскрывается по кодам IUPAC. Для каждого раскрытого варианта считается: 

 `tm` - температура плавления олигонуклеотида, 
 `dg` - энергия Гиббса образования полностью комплементарного дуплекса
 `hairpin_tm` - температура плавления шпильки (если возможна)
 `homodimer_tm` -  температура плавления гомодимера (если возможен)


### Про пропуски

Для неокоторрых вариантов шпильки или гомодимеры не существуют, термодинамическим показателям в таких вариантах присвоены NAN.

Сооответсвующие статистики считаются без учета NAN позиций.

### Выдача

`results/task1_thermo.xlsx` для каждого праймера статистики по соответвующим термодинамическим величинам:

- `median` — среднее
- `mean` — медиана
- `p5/p95` — 5 и 95 перцентили соотвественно
<br>
- `tm` — температура плавления олигонуклеотида
- `dg` — энергия Гиббса
- `harpin_tm` — температура плавления возможных шпилек
- `homodimer_tm`- температура плавления возможных гомодимеров

## Задание 2. Выдача blast 


### Таксономия

Получение полной таксономии находок: 

1. Accession → `taxid`: запрос `Entrez.esummary(db='nuccore')` на весь список
2. `taxid` → полная таксономия: через библиотеку `taxopy`: `Taxon.rank_name_dictionary` - выдает словрь соответсвий 

В задании указано работать с вирусными находками в образце: фильтр `'Viruses' not in taxon.name_lineage` оставляет вирусы и фаги.

`taxopy` при первом вызове `TaxDb()` качает `taxdump.tar.gz` с ftp NCBI во временную папку, и
делает это при каждом запуске скрипта. Поэтому архив лежит в репозитории, в `data/taxdump/`, и
скрипт читает дамп локально. Перед первым запуском архив надо распаковать:

```bash
tar -xzf data/taxdump/taxdump.tar.gz -C data/taxdump nodes.dmp names.dmp merged.dmp
```

Путь относительный, так что структуру папок надо сохранить, а скрипт запускать из его
собственной директории. `keep_files=True` нужно, чтобы taxopy не удалила файлы после ииспользования.

### Дедупликация и доли

Проверено: `groupby('qseqid').species.nunique()` - 0 последовательностей в образце выравниваются на несколько видов сразу. 
Однако в этой же выдаче одно прочтение может выровняться на один и тот же вид несколько раз.
Чтобы при вычислений статистик одна последовтельность не учавствовала 2 раза, строки сортируются по `bitscore` и остается лучшая. 
Прочтений с вирусными хитами 2121 при 2136 вирусных хитах, то есть дедупликация снимает 15
строк. 

Долей считается две:

- `share_virus` — от числа прочтений с вирусными хитами, состав вирусной части
- `share_all` — от числа прочтений, у которых вообще есть хоть одно выравнивание в выдаче

`Sinsheimervirus phiX174` пришедший как контроль в постановке Illumina исключён из рассчета.

### Выдача

`results/task2.xlsx` три листа:

- `taxonomy_species` — уникальные виды с полной линией до вида
- `taxonomy_subspecies` — то же с нижними таксонами
- `stats` — по каждому виду число прочтений, медианы identity, e-value и длины выравнивания,
  обе доли
